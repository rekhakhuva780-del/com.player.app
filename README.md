# Player (Video + IPTV) – Android APK

Package name: `com.player.app`

## APK kaise banaye
1. Ye poora folder GitHub repo me upload karo (branch: `main`).
2. Repo ke **Actions** tab me "Build APK" chalega (ya **Run workflow** dabao).
3. 5-8 min baad run khologe to neeche **Artifacts → Player-APK** milega. Download karke phone me install karo.

## Code change
App ka code `www/index.html` me hai. Edit karke push karo, naya APK ban jayega.
